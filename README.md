# Streaming Platform - Spring Boot 🎬

Aplicação web inspirada em uma plataforma de streaming (estilo Netflix), desenvolvida com Spring Boot, utilizando arquitetura MVC e persistência de dados com JPA.

## 📌 Sobre o Projeto

O projeto simula um sistema de streaming com autenticação de usuários e integração com banco de dados, aplicando conceitos de desenvolvimento backend com Java e Spring Boot.

## 🚀 Funcionalidades

- Cadastro de usuários
- Login com validação no banco de dados
- Persistência de dados utilizando JPA
- Estrutura organizada em camadas (MVC)
- Integração entre backend e páginas HTML
- Dashboard após autenticação

## 🛠️ Tecnologias Utilizadas

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- H2 Database
- HTML / CSS

## 🏗️ Arquitetura

O projeto segue o padrão MVC:

- **Controller** → Responsável pelas requisições HTTP
- **Service** → Regras de negócio
- **Repository** → Comunicação com o banco de dados
- **Model** → Entidades da aplicação
